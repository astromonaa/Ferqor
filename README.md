# Blockchain на Rust

Блокчейн, разрабатываемый на языке Rust. Проект находится на этапе активной разработки и включает майнинг, транзакции, кошельки, mempool и валидацию цепочки.

## 🚀 Возможности

- **Блокчейн с Proof-of-Work (PoW)**: Майнинг блоков с настраиваемой сложностью
- **Криптографические подписи**: Использование Ed25519 для подписи транзакций
- **Mempool**: Очередь транзакций с приоритизацией по комиссиям
- **Кошельки**: Генерация ключевых пар и создание подписанных транзакций
- **Адреса**: Генерация адресов из публичных ключей с использованием SHA-256
- **Merkle Tree**: Вычисление корня Меркла для транзакций в блоке
- **Валидация**: Полная проверка целостности блокчейна и транзакций
- **Nonce**: Защита от повторных транзакций
- **Coinbase**: Транзакции вознаграждения майнерам

## 📖 Использование

### Пример создания блокчейна и транзакции

```rust
use crate::config::GenesisConfig;
use crate::wallet::Wallet;
use std::collections::HashMap;

fn main() {
    // Создаем кошельки для Alice и Bob
    let alice = Wallet::new();
    let bob = Wallet::new();

    // Настраиваем генезис-блок с начальным балансом Alice
    let initial_config = GenesisConfig::get_config(
        Some(HashMap::from([(alice.address, 100)])), 
        None
    );

    // Создаем блокчейн с сложностью 4
    let mut blockchain = Blockchain::new(4, initial_config);

    // Alice создает транзакцию для Bob (50 единиц, комиссия 5)
    let tx = alice.create_transaction(bob.address, 50, 5, 0);

    // Проверяем валидность транзакции
    println!("Транзакция валидна: {}", tx.is_valid());

    // Добавляем транзакцию в блокчейн
    let success = blockchain.add_transaction(tx);
    println!("Транзакция добавлена: {}", success);

    // Майним pending транзакции (вознаграждение получает Alice)
    blockchain.mine_pending_transactions(alice.address);
}
```

## 🏗️ Архитектура

### Основные компоненты

#### 1. **Blockchain** (`src/blockchain/blockchain.rs`)
Основная структура блокчейна, содержащая:
- Цепочку блоков
- Mempool для pending транзакций
- Балансы адресов
- Nonce для защиты от повторов
- Сложность майнинга

**Ключевые методы:**
- `new()` - создание нового блокчейна с генезис-блоком
- `add_transaction()` - добавление транзакции в mempool
- `mine_pending_transactions()` - майнинг блока с pending транзакциями
- `is_valid()` - валидация всей цепочки блоков

#### 2. **Block** (`src/block/block.rs`)
Структура блока с:
- Заголовком (index, previous_hash, nonce, timestamp, merkle_root)
- Списком транзакций
- Хешем блока

**Ключевые методы:**
- `calculate_merkle_root()` - вычисление корня Меркла
- `calculate_hash()` - вычисление хеша блока (SHA-256)
- `mine_block()` - PoW майнинг с поиском nonce

#### 3. **Transaction** (`src/transaction/transaction.rs`)
Структура транзакции:
- `from` - адрес отправителя
- `to` - адрес получателя
- `amount` - сумма перевода
- `fee` - комиссия
- `nonce` - порядковый номер
- `signature` - Ed25519 подпись
- `public_key` - публичный ключ отправителя

**Ключевые методы:**
- `txid()` - вычисление идентификатора транзакции
- `is_valid()` - проверка подписи и публичного ключа
- `verify_signature()` - верификация Ed25519 подписи

#### 4. **Wallet** (`src/wallet/wallet.rs`)
Кошелек с:
- Приватным ключом (SigningKey)
- Публичным ключом (VerifyingKey)
- Адресом

**Ключевые методы:**
- `new()` - генерация новой ключевой пары
- `sign()` - подпись данных
- `create_transaction()` - создание подписанной транзакции

#### 5. **Mempool** (`src/mempool/mempool.rs`)
Очередь транзакций с:
- Хранилищем транзакций по ID
- Индексом по отправителям и nonce
- Приоритизацией по комиссиям

**Ключевые методы:**
- `insert()` - добавление транзакции
- `select_transactions()` - выбор транзакций для майнинга (по комиссиям)
- `remove_selected_transactions()` - удаление подтвержденных транзакций

#### 6. **Address** (`src/address/address.rs`)
Система адресов:
- 20-байтовые адреса (первые 20 байт от SHA-256 публичного ключа)
- Специальный адрес COINBASE для вознаграждений майнеров

#### 7. **BlockchainValidator** (`src/blockchain/validator.rs`)
Валидатор блокчейна:
- Проверка coinbase транзакций
- Валидация переходов состояний
- Проверка целостности балансов и nonce

#### 8. **GenesisConfig** (`src/config/genesis_config.rs`)
Конфигурация генезис-блока:
- Начальные балансы
- Максимальный вес блока
- Временная метка

## 🔐 Криптография

- **Хеширование**: SHA-256 для хешей блоков, транзакций и адресов
- **Подписи**: Ed25519 для подписи и верификации транзакций
- **PoW**: Поиск nonce с требуемым количеством ведущих нулей в хеше

## 🔍 Работа PoW

Майнинг блока работает путем перебора значений nonce до тех пор, пока хеш блока не будет иметь требуемое количество ведущих нулей в шестнадцатеричном представлении.

Пример для сложности 4:
- Требуется 4 ведущих нулевых символа в hex-представлении хеша
- Это эквивалентно 2 нулевым байтам
